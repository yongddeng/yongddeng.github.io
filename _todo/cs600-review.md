# cs600 series review

| Category | Score | Notes |
|----------|:-----:|-------|
| **Breadth** | 4.5 | Transistors to K8s in 7 posts. Missing algorithms/compilers/security, but the systems stack is complete. |
| **Depth** | 4.0 | Graduate-level in strongest sections (page tables, x86 virt, I/O multiplexing). Catalogue-mode in weaker ones pulls it down. |

| **Originality** | 4.0 | The ML thread through a systems curriculum is distinctive. Nothing else like it online. Loses points where it reads like condensed Tanenbaum/Kurose. |
| **Writing** | 3.0 | Honest gap vs the math posts. Term-heavy, list-heavy paragraphs. When it tightens (604 I arc, 607 1.2), it's a 4+. |

**Overall: 4.0** — the architecture is strong, the writing needs to catch up to it.

Strongest sections: 604 I/O multiplexing arc, 607 x86 virtualisation story, 601 roofline model.

Main weakness: catalogue paragraphs that list successive facts without a governing argument. The math posts never do this — every sentence is load-bearing for the next. Apply that same instinct here.

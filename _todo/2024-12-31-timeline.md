# Timeline

---

```
1940s   ENIAC, first electronic computers. One job at a time, manual setup.
        CPU idle between jobs.

1950s   Batch processing (GM-NAA I/O, 1956). Queue jobs, run sequentially.
        Still one job at a time, but no manual intervention between jobs.

1960s   Multiprogramming. Multiple jobs in memory. When job A waits on I/O,
        run job B. CPU utilisation jumps. (IBM OS/360, 1964)

        Time-sharing. Multiple users share one machine interactively.
        CPU cycles between users fast enough to feel responsive.
        (CTSS 1961, Multics 1964, Unix 1969)

1970s   Unix rewritten in C (1973). Processes, fork/exec, pipes.
        Concurrency = a few dozen processes on one CPU.
        Networking begins (ARPANET, 1969 → TCP/IP, 1974).

1980s   Personal computers. MS-DOS: single-tasking, one program at a time.
        Mac OS: cooperative multitasking (programs must yield voluntarily).
        A hung program freezes the whole system.

1990s   Preemptive multitasking arrives on desktops (Windows NT 1993,
        Linux 1991). OS forcibly switches via timer interrupt.

        World Wide Web (1991). Servers start handling hundreds, then
        thousands of concurrent connections. Thread-per-connection
        model (Apache, 1995). Each client = one OS thread.

1999    C10K problem identified (Dan Kegel). 10,000 concurrent connections
        collapse thread-per-connection servers. Memory exhaustion
        (10K × 1MB stacks = 10GB), scheduler thrashing.

2002    Event loop servers appear. epoll (Linux 2.5.44), kqueue (FreeBSD 2000).
        One thread polls thousands of FDs. nginx written (2002).
        Separation of waiting (FDs) from working (threads).

2004    Clock speed plateaus at ~4 GHz (Dennard scaling breaks down).
        Intel cancels Tejas. Industry pivots to multi-core
        (Athlon 64 X2, Pentium D, 2005).

        Software must now explicitly parallelise to get faster.
        Single-threaded programs stop benefiting from new hardware.

2006+   Language runtimes adapt:
        - Java adds java.util.concurrent (2004), ForkJoinPool (2011)
        - Go (2009): goroutines, m:n scheduling, built-in channels
        - Node.js (2009): single-threaded event loop for I/O servers
        - Rust (2015): ownership system prevents data races at compile time

2010s   Containers (Docker 2013, Kubernetes 2014) built on Linux cgroups
        and namespaces. Concurrency moves from threads within a process
        to processes across machines.

2020s   Async/await now standard in Python, JS, Rust, C#, Kotlin.
        Go adds async preemption (1.14, 2020).
        Java adds virtual threads (Project Loom, 2023).
        Python experiments with GIL removal (3.13, 2024).
```
